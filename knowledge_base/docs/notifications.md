# Smart Notification System

## Keeping Users Informed
The platform ensures that users never miss important updates. It features a robust notification engine that delivers alerts directly to the user's web dashboard and mobile device via push notifications.

## Targeted Alerts
Notifications are strictly event-driven to avoid spamming users. Alerts are instantly sent when crucial actions occur, such as:
- A mentor accepts a student's session request.
- A scheduled mentoring session is about to begin.
- An event the user RSVP'd to is updated or starting soon.
- A new review is left on a mentor's profile.

## Inbox Management
Users have a dedicated notification inbox where they can review all past alerts, mark them as read, or dismiss them to keep their workspace clean and organized.
