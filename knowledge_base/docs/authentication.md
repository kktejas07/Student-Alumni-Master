# Authentication and Security

## Account Security
Keeping user data secure is a top priority. When users create an account, their passwords are mathematically hashed and salted, meaning the original password is never stored or visible to anyone. 

## Secure Sessions
The platform uses encrypted digital tokens to keep users logged in securely as they navigate between different pages. These tokens ensure that users don't have to keep entering their passwords, while also making sure that unauthorized individuals cannot access their accounts.

## Two-Factor Authentication (2FA)
For an added layer of security, users can enable Two-Factor Authentication. When enabled, logging in requires both their standard password and a temporary, rotating code generated by an authenticator app on their mobile device. The platform also provides backup codes in case the user loses access to their authenticator app.

## Data Privacy
Highly sensitive personal information, such as private notes or detailed biographical data, is encrypted before it is ever saved to the database. This means that even if the database were compromised, the most sensitive information would remain completely unreadable without the secure decryption keys.
